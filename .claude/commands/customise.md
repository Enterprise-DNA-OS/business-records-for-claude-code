# Make the register yours

Read CLAUDE.md, docs/cli.md and docs/compliance.md. Clarify the exact field, rule and examples the operator wants. Back up the database and originals. Write a new numbered migration, never edit a migration already applied. Make the smallest CLI and report changes. Label local policy separately from cited law. Add a test that proves the new rule, run npm test, then apply npm run migrate to the selected workspace. Never shorten an existing retention period or clear a hold as a side effect. Show the changed record and explain the result. Do not delete originals or send anything.
