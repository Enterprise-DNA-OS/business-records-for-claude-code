# Prepare the Monday records review

First run attention, retention-due and compliance. Then run weekly-review to save those three sections. Summarise the owners and unresolved evidence gaps from that draft.

```bash
node scripts/records.mjs weekly-review
```

Use --json when composing a report. Keep originals and outputs private. Nothing sends, publishes or deletes from this workflow.
