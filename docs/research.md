# Target selection and sources

Checked 19 October 2026. Category: records-retention. Industry: professional firms. This is the business document archive and retention desk, distinct from the IT Glue build's equipment, runbooks and dependencies.

The current [DocuWare pricing page](https://start.docuware.com/faq/docuware-pricing) gives a typical Cloud range of $30 to $125+ per user per month. An illustrative 40-user configuration at the upper reference point is $60,000 annually before other costs. This is a scenario, not a customer invoice, binding quote or universal rate. Final pricing depends on user type, plan, storage and additions. The page uses only the vendor's stated per-user range, not the scenario total.

[Frontify pricing](https://www.frontify.com/en/pricing) does not give a fixed public price and its visual asset workflows are a poor fit. [Qualio pricing](https://www.qualio.com/pricing) is quotation-based. Its regulated validation requirements and overlap with the existing quality-management build make it unsuitable for this slot. Salesforce Media Cloud was checked and excluded because its family is already published in the registry.

Local customer brains and the available CRM snapshots were searched for DocuWare and M-Files. No verified usage or annual invoice was established. Live CRM usage was not verified. Search results include [G2 alternatives](https://www.g2.com/products/docuware/competitors/alternatives) and other comparison pages. This shows comparison intent exists, not measured search volume. The buyer and demand scores reflect those limits. No customer names are used publicly.
